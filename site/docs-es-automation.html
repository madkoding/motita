Actualizaciones y tareas programadas

Mantente en la última versión verificada y ejecuta tareas con una cadencia.

Actualizar

/update instala la versión más nueva. La pantalla de bienvenida y la barra lateral del navegador avisan cuando existe una. La descarga debe coincidir con el SHA256SUMS de la versión o no se instala nada. Un gateway iniciado con -serve se reinicia solo con el nuevo binario; una interfaz te dice que la reinicies.

El gateway informa su propia compilación en motita gateway status, así que tras instalar sobre un binario viejo puedes saber si el proceso que sigue corriendo es el anterior.

Las versiones se crean automáticamente a partir de commits semánticos: feat sube la versión menor, fix el parche y un cambio incompatible la mayor. La versión más nueva siempre aparece en la página de inicio.

Tareas programadas

Una tarea programada es una tarea o un plan que el gateway envía por sí solo, con una cadencia, sin nadie frente al teclado. Cada una es un pequeño archivo JSON en ~/.motita/schedules/ que puedes leer y editar a mano.

  • La cadencia es una duración (30m, 6h, 24h), no sintaxis cron. every 6h significa seis horas después de la última ejecución.
  • La cadencia más corta permitida es un minuto (schedule.min_every).
  • Una tarea puede ser un plan (solo lectura) o un task, y puede fijarse a una sesión.
  • Créalas, cámbialas, ejecútalas al instante y bórralas con /v1/schedules, o desde la interfaz.

La misma llamada desde código, en los lenguajes más usados (primero define MOTITA_TOKEN):

# crea un plan que se ejecuta cada 24 horas
curl -s -X POST "http://127.0.0.1:7477/v1/schedules" \
  -H "Authorization: Bearer $MOTITA_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"title":"nightly audit","task":"check the logs and report","kind":"plan","every":"24h"}'
const res = await fetch("http://127.0.0.1:7477/v1/schedules", {
  method: "POST",
  headers: {
    Authorization: "Bearer " + process.env.MOTITA_TOKEN, // el token del gateway: motita gateway start -token-only
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    title: "nightly audit",
    task: "check the logs and report",
    kind: "plan", // crea un plan que se ejecuta cada 24 horas
    every: "24h",
  }),
});
console.log(await res.json()); // la tarea programada, tal como queda guardada
import { env } from "node:process";

interface Schedule {
  title: string;
  task: string;
  kind: "plan" | "task";
  every: string;
}

const schedule: Schedule = {
  title: "nightly audit",
  task: "check the logs and report",
  kind: "plan", // crea un plan que se ejecuta cada 24 horas
  every: "24h",
};

const res = await fetch("http://127.0.0.1:7477/v1/schedules", {
  method: "POST",
  headers: {
    Authorization: "Bearer " + env.MOTITA_TOKEN, // el token del gateway: motita gateway start -token-only
    "Content-Type": "application/json",
  },
  body: JSON.stringify(schedule),
});
console.log(await res.json()); // la tarea programada, tal como queda guardada

package main

import (
	"fmt"
	"io"
	"log"
	"net/http"
	"os"
	"strings"
)

func main() {
	body := strings.NewReader(
		`{"title":"nightly audit","task":"check the logs and report","kind":"plan","every":"24h"}`,
	) // crea un plan que se ejecuta cada 24 horas
	req, err := http.NewRequest(http.MethodPost, "http://127.0.0.1:7477/v1/schedules", body)
	if err != nil {
		log.Fatal(err)
	}
	req.Header.Set("Authorization", "Bearer "+os.Getenv("MOTITA_TOKEN")) // el token del gateway: motita gateway start -token-only
	req.Header.Set("Content-Type", "application/json")

	res, err := http.DefaultClient.Do(req)
	if err != nil {
		log.Fatal(err)
	}
	defer res.Body.Close()
	out, _ := io.ReadAll(res.Body)
	fmt.Println(string(out)) // la tarea programada, tal como queda guardada
}
// Cargo.toml: reqwest = { version = "0.12", features = ["blocking", "json"] }, serde_json = "1"
use serde_json::{json, Value};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let token = std::env::var("MOTITA_TOKEN")?; // el token del gateway: motita gateway start -token-only
    let created: Value = reqwest::blocking::Client::new()
        .post("http://127.0.0.1:7477/v1/schedules")
        .bearer_auth(token)
        .json(&json!({
            "title": "nightly audit",
            "task": "check the logs and report",
            "kind": "plan", // crea un plan que se ejecuta cada 24 horas
            "every": "24h",
        }))
        .send()?
        .json()?;
    println!("{created}"); // la tarea programada, tal como queda guardada
    Ok(())
}
