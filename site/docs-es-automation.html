Actualizaciones y tareas programadas

Mantente en la última versión verificada y ejecuta tareas con una cadencia.

Actualizar

/update instala la versión más nueva. La pantalla de bienvenida y la barra lateral del navegador avisan cuando existe una. La descarga debe coincidir con el SHA256SUMS de la versión o no se instala nada. Un gateway iniciado con -serve se reinicia solo con el nuevo binario; una interfaz te dice que la reinicies.

El gateway informa su propia compilación en motita gateway status, así que tras instalar sobre un binario viejo puedes saber si el proceso que sigue corriendo es el anterior.

Las versiones se crean automáticamente a partir de commits semánticos: feat sube la versión menor, fix el parche y un cambio incompatible la mayor. La versión más nueva siempre aparece en la página de inicio.

Tareas programadas

Una tarea programada es una tarea o un plan que el gateway envía por sí solo, con una cadencia, sin nadie frente al teclado. Cada una es un pequeño archivo JSON en ~/.motita/schedules/ que puedes leer y editar a mano.

  • La cadencia es una duración (30m, 6h, 24h), no sintaxis cron. every 6h significa seis horas después de la última ejecución.
  • La cadencia más corta permitida es un minuto (schedule.min_every).
  • Una tarea puede ser un plan (solo lectura) o un task, y puede fijarse a una sesión.
  • Créalas, cámbialas, ejecútalas al instante y bórralas con /v1/schedules, o desde la interfaz.
curl -s -X POST -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"title":"auditoría nocturna","task":"revisa los logs y reporta","kind":"plan","every":"24h"}' \
  http://127.0.0.1:7477/v1/schedules
