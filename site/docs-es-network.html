Red y acceso remoto

Mantenlo en esta máquina, compártelo en tu LAN o llega desde un teléfono.

Por defecto el gateway responde solo en 127.0.0.1:7477, así que solo la máquina donde corre puede alcanzarlo. Todo lo que sigue es un paso deliberado fuera de eso.

Quién puede llegar

El primer gateway start pregunta una vez, y Ajustes → Red o motita gateway setup lo cambia después:

RespuestaResultado
Solo esta máquina (por defecto)Loopback.
La red localEscucha en todas las interfaces, con allow: ["lan", "!any"].
TodosEscucha en todas las interfaces sin reglas de origen.

gateway.allow es una lista ordenada de reglas (lan, una dirección, una red, cada una con prefijo ! opcional). Gana la primera que coincide, y loopback siempre se permite, así que no puedes dejarte fuera. El token sigue siendo la llave real; las reglas dicen desde dónde puede venir.

El gateway habla http plano. Fuera de loopback el token viaja sin cifrar, y el gateway te lo advierte al abrir.

Llegar de forma segura

  • Túnel SSH. ssh -N -L 7477:127.0.0.1:7477 el-host lo deja en http://localhost:7477 en tu computador, sin exponer nada.
  • Tailscale. Si Tailscale está corriendo, motita puede publicar el gateway con tailscale serve: https en el nombre de tu tailnet, accesible solo desde tus propios dispositivos. Funnel (internet pública) nunca se usa.
  • Un proxy inverso con TLS como Caddy delante de un gateway en loopback, o el segundo listener https del propio gateway (gateway.tls).

Por qué importa https

Los navegadores permiten el micrófono, las notificaciones de escritorio y el push al teléfono solo en https o localhost. Un teléfono en la LAN con http plano no obtiene ninguno, y es la razón habitual para elegir una de las opciones de arriba.

Notificaciones

Cuando termina el CI de un pull request, la página muestra un aviso. Las notificaciones al teléfono usan Web Push estándar desde el propio gateway, así que llegan con la página cerrada. En un iPhone o iPad la página debe agregarse antes a la pantalla de inicio (iOS 16.4 o posterior). Ajustes → Notificaciones tiene un botón de prueba de todo el camino.
