Skills: lo que aprende

Un estante de procedimientos que lee, escribe y mantiene ordenado, sin reentrenar.

motita mantiene una biblioteca de procedimientos: documentos que describen cómo se hace un tipo de trabajo, con los pasos, los comandos que funcionan y las trampas que alguien ya pagó. El modelo busca uno cuando lo necesita y escribe uno nuevo cuando aprende algo. Son archivos simples, así que puedes leerlos, corregirlos y versionarlos.

Cómo mejora

  • Una instalación nueva parte con procedimientos incluidos (ejecutar comandos, archivos, git, APIs HTTP, búsqueda web, toolchains, verificar un cambio, diagramas e informes).
  • Sin ajuste fino, sin API extra, sin cuenta extra. Un registro junto a un estante.

Ver y controlar el estante

El navegador tiene una ventana de Biblioteca de skills: cada documento, para qué sirve, cuántas veces se usó, el documento mismo renderizado, y un interruptor para apagar uno sin perderlo.

Un proyecto puede tener sus propios procedimientos en <proyecto>/.motita/skills/; se buscan primero y tapan a la biblioteca compartida.

El curador

Si se deja solo, un estante se pudre, así que un curador corre cada semana, solo cuando nadie ha hablado con motita en dos horas. No usa modelo para lo que importa y solo toca documentos que escribió el agente:

  • Sin uso por 14 días: se marca obsoleto, sigue buscable.
  • Obsoleto por 30 días más: se archiva, nunca se borra, un comando lo recupera.
  • Los documentos fijados quedan fuera de todo paso automático. Nada automático borra jamás.
motita curator status
motita curator run --dry-run
motita curator pin build-firmware
