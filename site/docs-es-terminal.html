La interfaz de terminal

La interfaz a pantalla completa que obtienes al escribir motita.

Ejecuta motita sin argumentos y obtienes una interfaz de terminal completa, escrita solo con la biblioteca estándar de Go.

Lo que ves

  • Quién responde. Una línea nombra el proveedor y el modelo, y cuánto piensa. Si falta la clave, lo dice con palabras y cómo agregarla.
  • Qué hará Enter. El cuadro de entrada lleva el modo como título. Task hace cambios y los demuestra con tu verificación. Plan solo lee y explica. Tab cambia de modo.
  • Las teclas que sirven ahora. El pie cambia mientras escribes un comando, mientras corre una tarea o mientras te desplazas hacia atrás.

Cómo corre una tarea

El agente nunca simula una verificación. Si falta una herramienta o sus dependencias, las instala como lo hace el proyecto y ejecuta el comando propio del framework (php artisan test, npm test, pytest). Un sustituto que solo devuelve 0, o editar un script de pruebas para que pase, se rechaza antes de tocar el disco. Si la máquina no puede ejecutar una verificación (sin red, una herramienta que no se puede instalar), el resultado dice no validado y da la causa, en lugar de informar un éxito.

Mantener el control

  • Esc detiene la tarea en curso.
  • Un mensaje escrito mientras el agente trabaja queda en cola y se envía al terminar.
  • / abre la lista de comandos. ? muestra todos los comandos y teclas. Una palabra suelta siempre es un mensaje, así que escribir new nunca ejecuta un comando por accidente.
  • Un turno fallido muestra el error tal como ocurrió más una pista para lo primero que encuentran quienes empiezan: Ollama apagado, una clave rechazada, un modelo inexistente, un límite de uso.

Comandos que conviene conocer

ComandoQué hace
/configRepite la configuración.
/modelsLista y cambia el modelo de esta conversación.
/sessions, /attach, /new, /backVer, unirse, abrir y dejar conversaciones. Una ejecución sigue mientras miras otra.
/agents (Ctrl+G)Los agentes en segundo plano y qué hace cada uno.
/gitConecta GitHub, GitLab o Bitbucket.
/artifactsArchivos que el agente guardó en esta conversación.
/languageCambia entre inglés y español al instante.
/updateInstala la versión más nueva.

Idioma

La terminal, el navegador y la configuración hablan inglés o español. Por defecto siguen el idioma de tu sistema; ui.language o /language elige uno para todas las interfaces.
