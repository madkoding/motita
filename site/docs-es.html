Documentación

Motita es un solo programa con varias partes. Elige la que quieras entender; cada página explica para qué sirve, cómo se usa y dónde está el detalle completo.

Instalación y primer uso

Un comando para instalar y una configuración corta la primera vez.

La interfaz de terminal

La interfaz a pantalla completa que obtienes al escribir motita.

Interfaz web y gateway

El mismo agente desde un navegador o un teléfono, servido por un solo puerto.

Proyectos, sesiones y git

Cada sesión trabaja en su propia rama; los pull requests se siguen por ti.

Modelos y proveedores

Trae tu propio modelo y elige uno distinto para cada tipo de trabajo.

Voz

Dicta a motita y haz que lea sus respuestas en voz alta.

Skills: lo que aprende

Un estante de procedimientos que lee, escribe y mantiene ordenado, sin reentrenar.

Seguridad y sandbox

Lo que nunca puede hacer, lo que pregunta y cuánto disco alcanza.

Red y acceso remoto

Mantenlo en esta máquina, compártelo en tu LAN o llega desde un teléfono.

El WebSocket

Una conexión bidireccional con banderas y latido, para programas que hablan con el gateway.

Actualizaciones y tareas programadas

Mantente en la última versión verificada y ejecuta tareas con una cadencia.

¿Buscas el detalle técnico?

Estas páginas explican. Para cada clave de configuración, cada endpoint y la arquitectura completa, lee la referencia o la guía completa (ambas en inglés). Para saber cómo se diseñó la interfaz de terminal, mira la revisión de diseño de la TUI.
