Modelos y proveedores

Trae tu propio modelo y elige uno distinto para cada tipo de trabajo.

motita no trae un modelo. Habla con el que ya usas, y el bucle que lo rodea es el mismo responda quien responda.

Proveedores

ProveedorCómo te conectas
OpenAI y cualquier host compatible con OpenAIAPI key
ChatGPT (Codex)Iniciar sesión con tu plan de ChatGPT
GitHub CopilotCódigo de dispositivo de GitHub
AnthropicAPI key
Suscripción de Claude (claude-code)claude auth login en el cliente de Anthropic
Google GeminiAPI key o tu propio inicio de sesión de Google
QwenAPI key de DashScope
OllamaNada en tu máquina; una API key para Ollama Cloud

Una API key siempre gana sobre una sesión guardada. Las claves que pegas van a un archivo aparte solo para tu usuario junto a la configuración (~/.motita/motita.env), así que la configuración puede versionarse y compartirse. Una clave nunca se envía de vuelta al navegador.

Desde el navegador

Ajustes → Proveedores lista cada proveedor, de dónde sale su clave, un campo para clave y endpoint, y un botón que prueba la conexión listando los modelos del proveedor. Copilot, Codex y Gemini pueden iniciar sesión con una cuenta desde la misma página (Qwen usa una clave de DashScope: su login gratuito con cuenta terminó el 2026-04-15).

Un modelo para cada tipo de trabajo

La pestaña Modelos fija el modelo por defecto y, debajo, uno para cada tipo de trabajo. Un tipo en Igual que el predeterminado sigue a la sesión.

TipoSe usa para
planTurnos en modo Plan
codeModo Task y agentes en segundo plano que escriben
reviewAgentes en segundo plano con rol de revisión
researchAgentes en segundo plano con rol de investigación
summaryTítulos, resúmenes de compactación, la suposición del modo auto

Un modelo potente para planificar y uno barato para resúmenes es una división común. Si el proveedor de un tipo no tiene clave, vuelve al modelo de la sesión y el registro lo dice.
